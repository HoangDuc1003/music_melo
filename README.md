# Melo

App nghe nhạc kiểu Spotify cho iPhone, dùng cá nhân: tìm và phát nhạc YouTube Music, tải về để nghe offline,
tắt màn hình vẫn phát. App chạy hoàn toàn trên điện thoại, không cần server.

> Dự án đang ở **giai đoạn khung**. Kế hoạch đầy đủ: [docs/PLAN.md](docs/PLAN.md).
> Ghi chú kỹ thuật cho người/AI làm tiếp: [CLAUDE.md](CLAUDE.md).

## Chạy thử trên máy tính

```bash
npm install
```

```bash
npm run dev
```

Mở http://localhost:5173, tìm một bài rồi bấm để phát (chế độ thử trên PC đi qua proxy của Vite).

## Cài lên iPhone

Bản iPhone được build trên GitHub Actions và cài bằng SideStore. Hướng dẫn chi tiết sẽ được thêm khi xong phần build.

## Lưu ý

Dự án chỉ dùng cho cá nhân, không phát hành lên App Store.
